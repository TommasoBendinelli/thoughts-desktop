## Loaded or linked at run time, not in this tree

- **Libraries Thoughts links against**: Qt 6 (LGPL-3.0-only), KDE Frameworks 6 (LGPL-2.0-or-later and others), Poppler
  (GPL-2.0-or-later), libgit2 (GPL-2.0-only WITH GCC-exception-2.0), OpenSSL 3 (Apache-2.0), zstd (BSD-3-Clause) and
  the other dependencies `CMakeLists.txt` looks for. Builds take them from the system or from KDE Craft.
- **Windows installer** (`tools/windows/installer/thoughts.nsi`, assembled by `tools/windows/cross/stage-runtime.py`):
  ships the KDE Craft libraries, plugins and data Thoughts needs (Qt, KDE Frameworks, Poppler and poppler-data,
  libgit2 with libssh2, OpenSSL, gpgme, D-Bus, shared-mime-info, …) and Microsoft's Visual C++ runtime DLLs
  (`vcruntime140*.dll`, `msvcp140*.dll`, `vcomp140.dll`) under Microsoft's redistribution terms. Each of those
  components keeps its own licence; a published installer should carry their licence texts.
- **macOS**: the app bundle loads its libraries from the KDE Craft root; nothing third-party is copied into it.
- **Agent notes** (`tools/mcp/agent_notes.py`): renders Markdown in headless Chrome with
  [marked](https://github.com/markedjs/marked) 12.0.2 (MIT) and [KaTeX](https://github.com/KaTeX/KaTeX) 0.16.11 (MIT;
  its fonts OFL-1.1). Neither is bundled in this tree or in a release: the script downloads these fixed versions
  (`marked.min.js`, and KaTeX's script, auto-render extension, stylesheet and fonts) from cdn.jsdelivr.net the first
  time a Markdown note is rendered and keeps them in the user's cache folder
  (`~/Library/Caches/Thoughts/agent-note-assets` on macOS; `THOUGHTS_AGENT_NOTES_ASSETS` names another). The browser
  that renders the note has no network access.
- **MCP server** (`tools/mcp/requirements.txt`): the Python MCP SDK (`mcp`, MIT), installed with pip.
