# Cross-building the Windows installer on Linux

`tools/windows/release.py` (run on the Mac) uses these files on a Linux builder: the SSH host named by `--builder` or `THOUGHTS_WINDOWS_BUILDERS`, in `$RB/wincross`, where `$RB` is `--builder-root` or `THOUGHTS_WINDOWS_BUILDER_ROOT` (default `~/thoughts-builder` on the builder). Everything runs in rootless podman containers that use the builder's own storage (`$RB/bin/thoughts-desktop-podman`, a `podman` wrapper the builder provides). The images build on `localhost/thoughts-desktop-build`, the builder's Linux build image of Thoughts (see `setup-builder.sh`).

| File | Role |
| --- | --- |
| `clangcl-toolchain.cmake` | CMake toolchain: clang-cl and lld-link with the Windows SDK and CRT from `xwin`, and KDE Craft's Windows libraries. |
| `build-in-container.sh` | Configures, builds (Release, ccache) and installs Thoughts into a stage folder. |
| `case-insensitive-overlay.py` | Writes a clang VFS overlay so Craft's headers are found case-insensitively, as on Windows. |
| `stage-runtime.py` | Picks the files the installer ships: Thoughts' install, plus the Craft DLLs, plugins and data it needs (by PE imports), plus the MSVC runtime. |
| `../installer/thoughts.nsi` | NSIS per-user installer and uninstaller. |
| `wine-smoke-test.sh` | Installs a setup.exe under Wine on a virtual display, runs the programs, takes a screenshot, uninstalls. |
| `setup-builder.sh` | Recreates the builder's tree from scratch. |

## What is in `wincross/`

- `xwin-sdk/`: Windows SDK 10.0.26100 and MSVC CRT 14.44, splatted on Linux by `xwin` 0.10, so the lower-case aliases exist. Copying the Mac's splat does **not** work: on a case-insensitive disk those aliases are missing.
- `craft-win/`: KDE Craft 26.05 Windows packages (Qt 6.11.1, KF 6.26, MSVC 2022), and gpgme from Craft's MinGW cache. They are unpacked on Linux; on the Mac, folders such as `threadweaver` and `ThreadWeaver` merge.
  - The archives are kept on the Mac in `~/tools/wincross/pkgs` (a download script there fetches the list). The MinGW gpgme packages are no longer on files.kde.org.
  - Since 2026-10-22 this includes `libs/libgit2` 1.7.1 (`libgit2-1.7.1-89-20260525T151238-windows-cl-msvc2022-x86_64.7z`, SHA-256 `209d4acf…0cec`): Craft builds it with WinHTTP for HTTPS and its `libssh2` for SSH, so `git2.dll` brings no new DLL besides itself. To add it to an existing builder, copy the archive to `pkgs/`, unpack it in `craft-win/` with the container's `7z x`, and point `lib/pkgconfig/libgit2.pc` at `craft-win` as step 3 of `setup-builder.sh` does.
- `craft-host/`: Linux build tools of the same Craft release (moc, rcc, uic, kconfig_compiler, msgfmt). Code generated by moc must match the Qt headers exactly.
- `vcredist/x64/`: `vcruntime140*.dll`, `msvcp140*.dll` and `vcomp140.dll` from Microsoft's redistributable package. They are deployed next to `thoughts.exe` (app-local), so the PC needs no VC++ Redistributable.
- `webview2-sdk/1.0.4314.35/`: Microsoft's WebView2 SDK, the NuGet package `Microsoft.Web.WebView2` 1.0.4314.35 (stable, 23 Oct 2026) from nuget.org, unpacked. The package is `pkgs/microsoft.web.webview2.1.0.4314.35.nupkg`, SHA-256 `90778deb1b77e36292828b4b5833c9255c27533f40e0ddd55891ae718944edc4` (its SHA-512 is the one in nuget.org's catalog).
  - Since 2026-11-25 live HTML pages, and web links of agent notes, open in a WebView2 of Thoughts' own (`part/htmllivewebview_win.cpp`); later that day embedded HTML pages and HTML editions too (`part/htmlpagewebview_win.cpp`, QWebView's interface for `HtmlDocumentView`, since Qt WebView has no Windows backend in Craft's packages). Both share `part/webview2host_win.cpp`. `build-in-container.sh` passes `webview2-sdk/<version>/build/native` as `THOUGHTS_WEBVIEW2_SDK` (another folder: set `WEBVIEW2_SDK`) and stops when it is missing. Thoughts links `x64/WebView2LoaderStatic.lib`, so no `WebView2Loader.dll` ships and `stage-runtime.py` has nothing to add.
  - The PC needs the WebView2 Runtime (part of Windows 11 and of updated Windows 10; Microsoft's Evergreen installer otherwise). Without it, and under Wine, `HtmlLiveWebView::available()` and `HtmlDocumentView::webViewAvailable()` are false and those pages open in the browser, as before.
  - To add it to an existing builder, run step 5 of `setup-builder.sh` in `wincross/`.
- `wt/`: the release worktree (`src`, `server/sdk`, `build`, `stage`, `runtime`). `dist/` holds the installers; `logs/` holds the build logs.

## Setting up a new builder

```sh
rsync -a ~/tools/wincross/pkgs ~/tools/wincross/xwin-cache BUILDER:thoughts-builder/wincross/
ssh BUILDER bash /path/to/src/tools/windows/cross/setup-builder.sh
```

## Smoke test

```sh
ssh BUILDER 'W=$HOME/thoughts-builder/wincross; $W/../bin/thoughts-desktop-podman run --rm --network none \
  -v $W:$W localhost/thoughts-winetest:20261015 bash $W/wt/src/tools/windows/cross/wine-smoke-test.sh $W/dist/Thoughts-<version>-setup.exe $W/smoke'
```

Under Wine some parts do not behave as on Windows (see `../README.md`, "Checking the build"). The smoke test only shows that the install is complete and that Thoughts starts.
